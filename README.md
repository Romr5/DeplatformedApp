# 📡 De-Platformed

> **Off-Grid, Zero-Internet P2P Mesh Communication Network**

De-Platformed is an offline-first communications ecosystem for mobile devices and web browsers using **Bluetooth LE & Wi-Fi Direct (Google Nearby Connections)**. It requires no internet, SIM card, cellular towers, or central servers.

## ⚡ Feature Summary
- 📶 **100% Offline P2P Mesh Network** (Google Nearby Connections API)
- 🔒 **End-to-End Encryption** (ECDH P-256 + AES-256-GCM)
- 🛡️ **Pairing Approval Prompt** (`Accept & Trust` vs `Reject`)
- 💾 **Trusted Device Memory** (Instant zero-prompt auto-reconnect)
- 💬 **Group Mesh & Private 1-on-1 Chats**
- 🔴 **One-Tap Disconnect & Unpair Controls**
- 📦 **Standalone Offline APK** (Includes bundled JS offline assets)
